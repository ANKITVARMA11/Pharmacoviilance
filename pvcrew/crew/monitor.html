What AutoGen did, step by step

AutoGen in 60 seconds

Agent

A Python object with a name. AutoGen hands it the new messages (on_messages) and it returns one reply. Here each agent calls the language model inside that method.

Team (group chat)

Several agents sharing one conversation. This crew uses GraphFlow: agents are nodes and arrows say who speaks next. The Critic's arrow back to Intake only fires when it says VERDICT: REVISE.

Everyone sees everything

Every reply is delivered to every participant. Each agent keeps its own memory of what it was shown, so the Critic can read what Intake and Coding said.

Who decides who speaks?

The manager, using the graph. No model is asked to choose, so the routing is predictable.

When does it stop?

When the last agent has no arrow out (Narrative), or a turn limit is reached as a safety stop. The case then waits for the human reviewer.
